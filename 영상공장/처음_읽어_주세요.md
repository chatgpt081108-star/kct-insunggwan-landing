# KCT학원 영상공장

원장님 영상(홍보 쇼츠, 셀카 쇼츠, 칠판 강의)을 만드는 작업 파일이에요.
새 대화에서 이어서 만들 때는 클로드에게 이렇게 말하면 돼요.

> 영상공장/처음_읽어_주세요.md랑 학원규칙.md 읽고, v3 목소리로 ○○ 영상 만들어 줘

## 먼저 알아 둘 것
- **학원규칙.md**: 학원 정보, 원장님 결정 사항(골드·블랙, 흰 자막 + 골드 포인트, 뺄 문구), 목소리 모델 번호가 적혀 있어요. 영상은 여기 적힌 사실만 써요.
- **목소리**: 피쉬 오디오의 비공개 모델 "형주연 원장님 v3 (KCT학원)"를 써요. 피쉬 키는 클라우드 환경 "우리학원 영상공장 (Fish Audio)"에 저장돼 있어서, 새 대화도 **이 환경을 골라야** 목소리를 쓸 수 있어요.
- **이 저장소는 공개(public)예요.** 원장님 녹음, 사진, 셀카 영상, 완성 영상은 일부러 넣지 않았어요. 필요하면 원장님이 새 대화에 다시 올려 주세요.

## 폴더
| 폴더 | 내용 |
|---|---|
| `shorts/` | 원장님 목소리(피쉬)로 읽는 세로 홍보 쇼츠. `script.json` 대본 → `tts.py` 목소리 → `build.py` 화면·자막·mp4 |
| `selfie_shorts/` | 원장님이 직접 찍은 셀카 영상 위에 카드·흰 자막·사진·마지막 장면을 얹는 쇼츠 |
| `chalkboard/` | 칠판 판서 강의(가로) 템플릿과 녹화 스크립트 |

## 다시 만드는 방법 (클로드용 메모)
### 홍보 쇼츠 (`shorts/`)
1. `script.json`의 `say`(자막)와 `parts`(끊어 읽기 단위)를 고쳐요. "KCT"는 `parts`에서 "케이씨티"로 써요.
2. `python3 tts.py <목소리 모델 id>` — 문장마다 읽히고 쉼표 뒤 0.3초, 문장 끝 0.5초 쉼을 넣어요. 늘어진 테이크는 자동으로 다시 읽혀요. 읽히기 전에 원장님께 대략 비용을 먼저 말해요.
3. `python3 build.py v5` — 결과는 `../../완성영상/`에 생겨요(이 저장소 밖, 작업 폴더 기준). 40초 이내로 맞춰요.
4. 2번 장면(강단)은 `img/director-cut.png`가 필요해요. 원장님 증명사진(흰 배경)을 받아 배경을 지운 PNG로 만들어 넣어요. 저장소에는 없어요.

### 셀카 쇼츠 (`selfie_shorts/`)
1. 원장님 셀카 영상을 받아 피쉬 받아쓰기(`/v1/asr`, 단어 시간 포함)로 말을 적어요.
2. 시험 삼아 한 말, 긴 쉼은 잘라 내고 `base.mp4`로 이어 붙여요(소리는 loudnorm -16 LUFS). 끝에 마지막 장면용 3.6초를 붙여요.
3. `plan.py`에 자막(원장님 실제 말, 받아쓰기 오류만 고침)과 카드 시간을 적고, `node render.js <길이>`로 투명 오버레이를 만든 뒤 ffmpeg로 합쳐요.

## 원장님이 정한 것 (요약)
- 색: 골드 + 블랙
- 자막: 파란 상자 쓰지 않음. 흰 글씨 + 핵심 단어만 골드
- 영상에 넣지 않음: "대한민국 최초의 인성교육 학원", 수강료
- 학생 얼굴 사진은 넣지 않음 (보호자 동의 받은 것만)
